# Noviq Admin Panel

Admin dashboard for the Noviq Electronics e-commerce platform.

## Features

- Admin authentication
- Dashboard
- Product management
  - Add products
  - Edit products
  - Delete products
- Category management
- Order management
- Update order status
- Firebase REST API integration

## Tech Stack

- React.js
- Vite
- JavaScript
- Firebase REST API
- Firebase Authentication REST API
- Firebase Realtime Database
- Vercel

## Run Locally

```bash
npm install
npm run dev
